How it behaves now:

Default is triple pendulum.
You can switch to double by passing env-id.
Examples:

Triple (default):
bash submit_and_watch_hpc.sh
Double:
bash submit_and_watch_hpc.sh --env-id InvertedDoublePendulum-v5
Practical note:

Triple uses your custom repo env and should run without MuJoCo.
Double uses MuJoCo Gym env, so it needs MuJoCo dependencies available on the HPC job environment.


Continue training from an existing checkpoint:
HPC (auto-infers episode offset from filename if it contains _ep335_):
bash scripts/submit_and_watch_hpc.sh --episodes 2000 --env-id InvertedTriplePendulum-v0 --resume-actor-weights artifacts/model_pendulum_j3_ep335_YYYYMMDD_HHMMSS_invertedtriplependulum_v0_actor.weights.h5
Note: replace YYYYMMDD_HHMMSS with your real checkpoint timestamp.
Find the real filename with: ls artifacts/*ep335*actor.weights.h5

HPC (force offset manually if filename does not include episode number):

HPC (auto-pick highest episode checkpoint so you do not paste filenames each time):
bash scripts/submit_resume_latest_hpc.sh --episodes 2000 --env-id InvertedTriplePendulum-v0
